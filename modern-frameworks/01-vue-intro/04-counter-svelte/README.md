# Лічильник на Svelte

## Що це

Та сама задача засобами Svelte. Головна відмінність не в синтаксисі, а в тому,
коли виконується робота: більшу її частину бере на себе складальник.

## Як воно працює

`$state` позначає значення як реактивне, після чого з ним працюють як зі
звичайною змінною: `count += 1`. Ніяких `.value` і жодних функцій-оновлювачів.

`$derived` описує похідне значення — відповідник `computed` з інших
фреймворків.

Найважливіше видно не в коді, а в результаті збірки. Svelte компілює компонент
у прямі операції з DOM, тому в готовий застосунок не потрапляє бібліотека, яка
узгоджувала б стан із розміткою під час роботи.

## Як запустити

```bash
npm install && npm run dev
```

## Що має вийти

Поведінка та сама, що й у решті прикладів.

## Що спробувати далі

Зберіть усі п'ять прикладів і порівняйте розміри файлів у `dist`. Різниця
пояснюється саме тим, що потрапляє в застосунок: рантайм фреймворка або
згенерований код.
