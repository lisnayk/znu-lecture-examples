# Лічильник без фреймворка

## Що це

Найпростіший інтерфейс зі станом: число, дві кнопки й список записів. Написаний
без жодної бібліотеки, лише засобами браузера. Решта прикладів лекції розв'язує
рівно цю саму задачу, тому їх можна класти поруч і порівнювати рядок у рядок.

## Як воно працює

Стан лежить в об'єкті `state`. Розмітка створюється рядком і вставляється через
`innerHTML`, після чого посилання на потрібні вузли зберігаються в `el`.

Уся суть прикладу — у функції `render`. Вона окремо оновлює число, окремо
підпис із кількістю, окремо список. Кожен новий елемент інтерфейсу додає до неї
ще один рядок, і жоден із них не пов'язаний із даними автоматично: зв'язок
існує лише тому, що його щоразу пишуть руками.

Обробники подій змінюють `state` і викликають `render`. Забути цей виклик —
типова помилка: дані вже нові, а на екрані старі.

## Як запустити

```bash
npm install && npm run dev
```

## Що має вийти

Сторінка з нулем і двома кнопками. «Додати» збільшує число й додає запис
із часом на початок списку, «Очистити» повертає початковий стан.

Перевірка збірки, та сама, що й у решті прикладів:

```bash
./run.sh
```

## Що спробувати далі

Додайте підпис «останній запис» під числом. Знадобиться ще один вузол, ще одне
посилання в `el` і ще один рядок у `render` — саме це зростання й обговорюється
на лекції.
