# Лічильник на Vue

## Що це

Та сама задача, що й у прикладі без фреймворка, але стан оголошено реактивним,
а розмітка описана шаблоном.

## Як воно працює

`ref` робить значення реактивним: Vue помічає запис у `.value` і перемальовує
ті частини сторінки, які це значення читають. Функції `render` тут немає взагалі,
і саме її відсутність варто показати поруч із першим прикладом.

`computed` описує похідне значення. Воно не зберігається окремо й не потребує
оновлення: перераховується тоді, коли змінилося те, від чого залежить.

У шаблоні `v-for` розгортає список, `v-if` показує підпис для порожнього
списку, `@click` прив'язує обробник. Атрибут `key` потрібен, щоб під час
перемальовування Vue зіставляв елементи між собою, а не переставляв їх наосліп.

## Як запустити

```bash
npm install && npm run dev
```

## Що має вийти

Сторінка поводиться так само, як приклад без фреймворка. Різниця не в поведінці,
а в тому, скільки коду знадобилося й скільки місць доведеться правити при
наступній вимозі.

## Що спробувати далі

Додайте підпис «останній запис» — вистачить одного `computed` і одного рядка
в шаблоні. Порівняйте з тим, що для цього довелося зробити в першому прикладі.
