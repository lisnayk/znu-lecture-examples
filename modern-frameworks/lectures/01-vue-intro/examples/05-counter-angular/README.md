# Лічильник на Angular

## Що це

Та сама задача засобами Angular — прикладу повного фреймворка, де компонент,
типізація і складальник задані наперед, а не збираються з окремих пакетів.

## Як воно працює

Компонент — це клас із декоратором `@Component`, у якому вказано селектор
і шаблон. Стан описано сигналами: `signal` зберігає значення, `computed`
описує похідне.

Сигнал читають викликом — `count()`, а записують методами `set` і `update`.
Явна межа між читанням і записом дозволяє фреймворку відстежувати залежності
без додаткових оголошень.

У шаблоні використано керівні блоки `@for` і `@if`. Це синтаксис самого
Angular, а не JavaScript, тому шаблон компілюється, а не виконується як вираз.

Проєкт зібрано власним інструментом Angular, а не Vite напряму, тому структура
каталогів відрізняється від решти прикладів: конфігурація складання лежить
в `angular.json`, а вихідні файли — у `src/app/`.

## Як запустити

```bash
npm install && npm start
```

## Що має вийти

Поведінка та сама. Відмінність, яку варто показати, — обсяг наперед заданих
рішень: TypeScript, структура проєкту й складальник тут не вибираються.

## Що спробувати далі

Відкрийте зібраний файл у `dist` і знайдіть у ньому текст із шаблону. Дослівно
його там немає: складальник екранує не-ASCII символи, тому пошук працює лише
після зворотного перетворення. Саме тому дим-тест написано на Node, а не на grep.
