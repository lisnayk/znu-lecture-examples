# FRAME — галерея без бібліотек

Приклад до лекції 2. Той самий макет у двох станах:

- `gallery-design.html` — початковий макет одним файлом, як його
  віддав дизайн;
- `gallery-bem/` — той самий макет, розкладений на три файли
  (`index.html`, `styles.css`, `gallery.js`) і названий за БЕМ.

Другий варіант і є вихідною точкою для прикладу `../02-gallery-vue`:
кожен блок БЕМ там стає окремим компонентом Vue. Коментарі у файлах
називають цю відповідність явно, блок за блоком.

## Запуск

Бібліотек і складання немає. Достатньо будь-якого статичного сервера —
наприклад, вбудованого в Python:

```bash
python3 -m http.server 8000
```

Далі відкрити http://localhost:8000/gallery-bem/ (початковий макет —
http://localhost:8000/gallery-design.html). Зупинка: Ctrl+C.

Файли відкриваються і просто подвійним клацанням: зовнішніх модулів
тут немає, тому протокол `file://` теж працює.

Фотографії завантажуються з Unsplash, тому потрібне підключення до
мережі; без нього макет покаже повідомлення про помилку.

## Що дивитися в коді

Класи відповідають лише за вигляд, скрипт чіпляється за атрибути
`data-role`. Перейменування класу не ламає логіку, і навпаки.

Кожна зміна стану вимагає ручного оновлення розмітки —
`renderPhoto`, `renderInfo`, `renderNav`. Забути один виклик означає
показати опис одного кадру поруч із фотографією іншого. Реактивність
Vue прибирає саме цей клас помилок.
