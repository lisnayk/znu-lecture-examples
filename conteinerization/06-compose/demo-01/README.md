# Демо 1. Legacy Vue 2

Для цього проєкту в `package.json` зафіксовано Node 14. Файл `.npmrc` вмикає перевірку цього обмеження під час встановлення залежностей. Для порівняння виконайте на хості `node --version`. Якщо тут установлено новішу версію, команда `npm ci --dry-run --no-audit --no-fund` має завершитися помилкою `EBADENGINE`. Параметр `--dry-run` дає змогу перевірити встановлення без запису залежностей.

```bash
docker compose up -d
docker compose exec ui node --version
docker compose exec ui node -p "require('vue').version"
```

Після запуску перегляньте журнали командою `docker compose logs -f ui`. Коли в журналі Vite з’явиться повідомлення `ready`, натисніть `Ctrl+C`, щоб вийти з перегляду журналів.

У контейнері має бути Node `v14.21.3` і Vue `2.7.16`. Відкрийте [127.0.0.1:5174](http://127.0.0.1:5174/) та натисніть кнопку. Vite в журналі показує порт 5173 усередині контейнера. Для браузера Compose публікує порт 5174 хоста. Лічильник має збільшитися.

Compose монтує весь каталог проєкту в /app. Окремий том dependencies містить залежності контейнера в /app/node_modules. Контейнер використовує npm 9, бо Rollup у цьому наборі залежностей потребує npm 8 або новішого. Цей приклад відтворює середовище старого застосунку. Порт опубліковано лише на loopback-інтерфейсі.

```bash
docker compose down
```
