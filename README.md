# Код прикладів до лекцій

Робочий код, який показується на лекціях. Кожен приклад самостійний: заходьте в його каталог і запускайте.

Це дзеркало, а не місце для роботи. Правки робляться у джерелі й
приїжджають сюди наступною публікацією.
