# Приклади до теми «Бази даних»

[Laravel CRUD з MySQL](laravel-mysql/README.md) веде каталог сервісів,
застосовує міграції при старті та підтримує EC2 → RDS Proxy → RDS MySQL.
Пароль у хмарному режимі отримується із Secrets Manager через роль EC2.

Для локального запуску потрібні PHP 8.3+, Composer і MySQL.
Порядок підготовки та EC2 user data містяться в README прикладу.
